As of 5 October 2026, this repository is a public assessment simulation for the attached NxtWave Growth Intern challenge and the `NxtWave_Campus_Relay_PRD.md`. User requested an end-to-end build. Implemented: two home entry buttons: student creates a fresh workspace and admin reopens that recent workspace in the same browser, or creates a seeded dashboard on first visit. Seven-day SQL workspaces have seed/reset. A seven-part conversational Matchmaker uses branch-specific challenges or a typed idea, then asks two bounded live AI follow-ups about use and a first-hour result; on AI failure it labels guided fallback questions. The OpenAI Responses API uses the full transcript to return three labelled proposals with personal fit, hypothetical usage and a first-hour demonstration. Selecting any proposal reveals an input-to-output flow and an editorially checked linked real-world precedent. The model can select only a verified precedent ID, never invent a source URL. Curated fallback examples and starter ZIPs, a three-question fictional registration chat with HMAC digest and unique constraint, cross-browser invite/pair, attribution, an operator dashboard with labelled channel sources/CSV and separate valid-friend metric, editable forecast/budget, three proposal views, link generator and editable partner copy are implemented. The API key is a sensitive Vercel Production variable, never in source. AI calls are capped per visitor, workspace and IP per day; raw ideas are not stored in the application database. No real campaign, actual students, approved syllabus or real A/B outcome is claimed.
