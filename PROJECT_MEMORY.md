# Campus Relay Project Context

As of 5 October 2026, this repository is a public assessment simulation for the attached NxtWave Growth Intern challenge and the `NxtWave_Campus_Relay_PRD.md`. User requested an end-to-end build. The challenge document is task material; it does not authorise real outreach, form submission, or a candidate-impersonated video.

Live URL: https://campus-relay-growth.vercel.app. Public source: https://github.com/Ajey95/campus-relay-growth. Vercel project `campus-relay-growth` under `ajeyas-projects-ac1f8c11`; free Neon resource `campus-relay-db` in `sin1`. Public deployment protection is disabled only for this newly created demo project. Database credentials and `EMAIL_HASH_SECRET` are in Vercel environment variables and ignored local `.env.local`, never in source.

Implemented: two home entry buttons: student creates a fresh workspace and admin reopens that recent workspace in the same browser, or creates a seeded dashboard on first visit. Seven-day SQL workspaces have seed/reset. A five-question guided conversational Matchmaker uses branch-specific challenges and a free-text idea route; the OpenAI Responses API returns three labelled proposals with personal fit and a first-hour demonstration. Curated fallback examples and starter ZIPs, a three-question fictional registration chat with HMAC digest and unique constraint, cross-browser invite/pair, attribution, an operator dashboard with labelled channel sources/CSV and separate valid-friend metric, editable forecast/budget, three proposal views, link generator and editable partner copy are implemented. The API key is a sensitive Vercel Production variable, never in source. AI calls are capped per visitor, workspace and IP per day; raw ideas are not stored in the application database. No real campaign, actual students, approved syllabus, real A/B outcome, or candidate video.
